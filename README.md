# Bank Account Management System

## About the Project
This is a simple Java-based Bank Account Management System developed using Object-Oriented Programming (OOP) concepts.

The program allows users to create bank accounts, deposit money, withdraw money, check account balances, and display account details.

## Features
- Create bank accounts using a parameterized constructor.
- Deposit money into an account.
- Withdraw money from an account.
- Check the current account balance.
- Display account details.
- Handle insufficient balance during withdrawal.
- Maintain independent balances for different accounts.

## Concepts Used
- Classes and Objects
- Constructors
- Instance Variables
- Methods
- Conditional Statements

## Technologies Used
- Java
- JDK
- Visual Studio Code

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Compile the program:

   `javac Main.java`

4. Run the program:

   `java Main`
